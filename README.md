# RCB_Strategy_Auction_Analysis
Royal Challengers Bangalore (RCB) Strategy &amp; Auction Analysis | SQL, Data Analytics
Conducted comprehensive SQL analysis on multi-season IPL datasets to diagnose historical performance bottlenecks and venue-specific variances.
Computed core performance metrics including Powerplay Run Rates, Death Overs Economy, and Batting Dependency Indices to quantify top-order reliance.
Formulated a venue-adapted toss and gameplay framework optimized specifically for high-scoring dynamics at M. Chinnaswamy Stadium.
Engineered a statistical model evaluating player performance consistency (low standard deviation) and versatility to output a cost-effective auction target shortlist.
